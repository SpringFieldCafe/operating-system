# Operating System

操作系统课程实验仓库，包含已完成的实验 2 和实验 4。实验 2 使用 Python 进程池驱动 ManimGL 交互动画；实验 4 使用 Jupyter Notebook 展示动态优先数进程调度。实验 5 已取消。个人原始报告与隐私检查中间文件仅在本地保存。

## 实验内容

| 实验 | 主题 | 主要要求 | 实验说明 |
| --- | --- | --- | --- |
| 实验 2 | 进程同步程序设计 | 模拟四个角色放取水果，盘子容量为 2；通过并发控制实现同步与互斥，并展示动画 | [操作系统-实验2.doc](exp2/doc/操作系统-实验2.doc) |
| 实验 4 | 进程调度 | 用 PCB 链式队列模拟五个进程的动态优先数调度，逐步显示队列与状态变化 | [操作系统-实验4-公开版.doc](exp4/doc/操作系统-实验4-公开版.doc) |

实验的完整要求以对应的 `.doc` 文档为准，可使用 Microsoft Word 或兼容的文档阅读器打开。

实验 2 的启动命令、交互操作、七个考点场景及源码打包方式见 [实验 2 使用说明](exp2/README.md)。

实验 4 的完整程序、实验说明、上机步骤、默认数据、运行结果和总结均在 [实验 4 Notebook](exp4/src/实验4_动态优先数进程调度.ipynb) 中。GitHub 可直接查看静态结果；交互按钮需要下载后在 Jupyter 中运行。从仓库根目录执行：

```powershell
python -m pip install --timeout 60 -r exp4/requirements.txt
python -m jupyter lab
```

打开 Notebook，选择 Python 3 内核，运行全部单元格，再通过“初始化”“单步调度”“运行到结束”操作五个进程。
