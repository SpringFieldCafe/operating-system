操作系统课程实验资料仓库，收录实验 2 和实验 5 的实验说明，并为后续实现保留目录结构。目前尚未提交实验程序或个人实验报告。

## 实验内容

| 实验 | 主题 | 主要要求 | 实验说明 |
| --- | --- | --- | --- |
| 实验 2 | 进程同步程序设计 | 模拟四个角色放取水果，盘子容量为 2；通过并发控制实现同步与互斥，并展示动画 | [操作系统-实验2.doc](exp2/doc/操作系统-实验2.doc) |

实验的完整要求以对应的 `.doc` 文档为准，可使用 Microsoft Word 或兼容的文档阅读器打开。

## 隐私处理

首次发布前已检查两个文档的正文、页眉页脚、批注、修订、嵌入内容和文档属性。正文未发现姓名、学号、身份证号、手机号或邮箱；文档中不存在图片、批注或修订记录。

原文件的作者、最后保存者和内部作者记录包含个人姓名，已清除。发布版保留 `.doc` 格式，实验正文及页面显示与原件一致。未脱敏原件和检查过程中生成的文件只保存在本地，并由 `.gitignore` 排除。

`.gitignore` 还排除凭据、环境配置、编辑器缓存、构建产物及个人实验报告。个人报告通过隐私检查后，可以为具体文件添加忽略规则例外；不要直接解除整个报告目录的忽略规则。

后续提交仍须检查正文、截图、附件、文档元数据、文件路径和提交身份。忽略规则不能替代内容审查，也不会清除已经进入 Git 历史的信息。
